# AI Ustad G V4.6.2 — Mandatory PPTX Visuals

This complete deployment retains V4.6.1 Netlify background generation, Gemini/Groq and existing website design.

## PowerPoint changes
- Embedded topic-category educational SVG illustration (actual image asset inside PPTX) for computing, science, mathematics, earth topics and general learning.
- Editable concept map built from lesson topic and generated learning outcomes.
- Editable 5E process diagram and editable comparison table.
- Mandatory visual presence checks refuse export if any visual type was not created.
- The 15-slide selection does not delete mandatory visual slides.

## Important scope
Embedded illustrations are original programmatically drawn vector illustrations, NOT AI-generated photos or fetched stock photographs. They are topic-category-aware, not guaranteed to accurately depict every niche lesson. The PPTX contains actual embedded image assets. Native diagrams and tables are editable. Images are not editable as PowerPoint shapes.

## Deployment
Unzip contents at repository root, commit, and deploy to Netlify. Keep API keys in Netlify environment variables. Test generated files and multilingual labels before production use.
